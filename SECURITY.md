# Security Policy

## Supported Versions

For security purposes, the following versions are supported:

| Version | Supported          |
| ------- | ------------------ |
| 5.7+    | :white_check_mark: |
| < 5.7   | :x:                |

## Reporting a Vulnerability

To report a vulnerability to the PressForward team, please use the 'Report a vulnerability' tool under the 'Security and Quality' tab of this repository. See https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately for more details.
